Anchik.net Anchik Beads Studio – программа для создания схем из бисера.
С помощью этой программы можно легко воплотить в жизнь любые Ваши бисерные фантазии. Вы сможете с легкостью изобразить схему, а после по ней сделать красивый браслет, колье, серьги или что-нибудь еще.
Программа поддерживает три техники бисероплетения: монастырскую (крестик), мозаичную (мозаика), ручного ткачества(квадрат). Для любителей браслетов с именами и рисунками эта программа просто незаменима! К тому же для пользователей программы доступна справка с наглядной информацией по каждой из техник. И кроме того, созданные вами схемы вы можете сохранить в специальном формате .bead который сможете позже открыть в этой же программе для последующего редактирования, или поделится с друзьями которые так же смогут внести свои идеи. Если вы просто хотите выложить в интернет картинку Вашей схемы – просто сохраните ее в одном из графических форматов (.jpg, .png, .tiff, .gif) прямо из программы.
